# Support Guide

Thank you for using Neuro AI! This document outlines where and how to get help, report issues, and propose enhancements.

---

## Official Channels

The only official channels for Neuro AI support and communication are hosted directly on GitHub:

- **Repository:** [https://github.com/Avenash005/Neuro](https://github.com/Avenash005/Neuro)
- **Issue Tracker:** [https://github.com/Avenash005/Neuro/issues](https://github.com/Avenash005/Neuro/issues)
- **Discussions / Q&A:** [https://github.com/Avenash005/Neuro/discussions](https://github.com/Avenash005/Neuro/discussions)
- **Security Advisories:** [https://github.com/Avenash005/Neuro/security/advisories](https://github.com/Avenash005/Neuro/security/advisories)

*Note: There are currently no official external Discord, Slack, or Telegram channels. Be cautious of unofficial third-party groups.*

---

## Where to Get Help

### 1. General Questions & Discussions
For questions about configuring local folders, connecting AI providers, or understanding architecture:
- Start a discussion in [GitHub Discussions](https://github.com/Avenash005/Neuro/discussions).
- Search previous issues and documentation in the [`docs/`](docs/) directory.

### 2. Reporting Bugs
If you encountered unexpected behavior or errors:
- Search [existing issues](https://github.com/Avenash005/Neuro/issues) to verify it hasn't been reported.
- Open a new issue using the structured **Bug Report** template.
- Include:
  - Your environment details (OS, Node.js version, browser).
  - Exact reproduction steps.
  - Expected vs. actual behavior.
  - Sanitized console or terminal logs (**never include API keys or private tokens**).

### 3. Feature Requests & Enhancements
If you have ideas for new connectors, privacy controls, or UI improvements:
- Open a new issue using the structured **Feature Request** template.
- Provide the problem statement, proposed implementation, and acceptance criteria.

### 4. Security Reports
For potential security vulnerabilities, private data leakage, or credential exposure:
- Refer to [SECURITY.md](SECURITY.md).
- Submit via [GitHub Private Vulnerability Advisory](https://github.com/Avenash005/Neuro/security/advisories/new).
